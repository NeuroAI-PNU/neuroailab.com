# 랩 이미지 시안 (2026-09-13)

최종본은 생성형 모델 + SVG로 다시 만들 계획이며, 이 폴더의 파일은 **구성 확정용 시안**입니다.

## 확정된 구성 (시안 B, 동심원)

가운데서 바깥으로 스케일이 커지는 다섯 겹의 동심원. "From molecule to behavior."

| 고리 | 내용 | 색 |
|---|---|---|
| 1 (중심) | 분자 · 약물 (AI 신약 개발) | 진보라 `#7B3FA0` |
| 2 | 이온채널 · 시냅스 (분자동역학) | 보라 `#B05CD6` |
| 3 | 뉴런 (NEURON 모델) | 주황 `#F0A94A` |
| 4 | 회로 · 네트워크 (NetPyNE, SNN) | 초록 `#3FA36B` |
| 5 (바깥) | 의사결정 · 행동 — 사람 / 동물 / 에이전트, 강화학습 | 하늘 `#5BD0F0` (아이콘 `#2A9DBD`) |

- 바깥 두 고리(4, 5)를 가로지르는 **Neuroscience ⇄ AI** 양방향 곡선 화살표 (왼쪽).
- RL 순환 고리는 넣지 않음. 하단 문구에만 "reinforcement learning".
- 주황·초록·하늘색은 기존 로고 색을 계승, 보라는 분자 스케일용으로 추가.

## 크기별 버전

| 버전 | 용도 | 포함 요소 | 파일 |
|---|---|---|---|
| Large | 첫 화면 히어로, 소개 자료 | 전체: 고리 5개, 아이콘, 라벨, 화살표, 제목, 하단 문구 | `concept-b-large.svg` |
| Medium | 상단 로고(약 300px), SNS 프로필 | 고리 5개 + 아이콘. 글자·화살표 없음, 선 1.8배 | `concept-b-medium.svg` |
| Small | 파비콘(16–64px), 앱 아이콘 | 고리 3개(하늘·주황·보라) + 분자 육각형만 | `concept-b-small.svg` |

## 생성형 모델 단계에서 지킬 것

- 정방형, 배경 투명 또는 흰색. 다크모드에서는 흰 배경 원판 위에 얹음.
- 아이콘은 단색 라인 스타일(선 굵기 통일), 사실적 렌더링 금지 — Small까지 축소되어도 색 고리가 읽혀야 함.
- 글자는 SVG 텍스트로 나중에 얹으므로 이미지 안에 글자 넣지 않음.
- 사람·동물·에이전트 아이콘은 성별·인종이 드러나지 않는 실루엣.
